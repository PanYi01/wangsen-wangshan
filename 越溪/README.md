## 🏪 旺山景区核心业态

### 遇见卢浮宫文创街区

旺山核心商业区，汇集面包、咖啡、文创、亲子体验于一体。

### 雨火窑炉面包店

王森文创旗下，果木柴火窑烤 + 天然酵母，每日限量手工面包。
- **位置**：遇见卢浮宫 J-20号
- **营业**：周一/二 09:30-18:00
- **招牌**：紫米奶酪软欧 ¥18-22、海盐卷 ¥12

### 知味恋歌咖啡

王森文创旗下精品咖啡馆，主打法式甜点与精品手冲。
- **特色**：树屋空间、山景露台、法式甜点
- **人均**：¥60-80

## 🗺️ 旺山游览指南

### 交通
- 导航：旺山遇见卢浮宫
- 停车：遇见卢浮宫街区（咕咕乐园赠2.5h停车券）

### 推荐路线
1. 上午 10:00 — 咕咕乐园遛娃
2. 中午 12:00 — 雨火窑炉面包（上午出炉，款式最全）
3. 下午 14:00 — 知味恋歌咖啡下午茶
4. 傍晚 — 九龙潭、茶园散步
